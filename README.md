# 新商品アイデア共有アプリ

新商品のアイデアを**店舗をまたいで社内で共有**し、レシピ（材料・分量・作り方・原価）まで一緒に貯めておくためのアプリです。

「**何月に採用した案はこれ**」「**今度のイベントの採用案はこれ**」を、一覧の上部で切り替えて見られることが中心機能です。

- 画面：Google Apps Script のウェブアプリ（URLを1本配るだけ。PC・スマホ両対応）
- データ：Google スプレッドシート（4シート＋写真はGoogleドライブ）
- ログイン：**合い言葉**を1つ社内で共有する方式（個人アカウント不要）

---

## できること

| 機能 | 内容 |
|---|---|
| アイデアの登録・共有 | 商品名・キャッチコピー・提案者・提案店舗・概要 |
| **採用月で切り替え** | 「2026年9月に採用した案」だけを一覧表示 |
| **イベントで切り替え** | 「秋の物産展の採用案」だけを一覧表示 |
| ステータス管理 | 提案中 / 検討中 / 採用 / 見送り |
| カテゴリ | 商品の種類。マスタで管理（惣菜・デザート・麺 など） |
| **タグ** | 誰でも自由に付けられる横断ラベル（SNS映え・春の定番 など） |
| 店舗マスタ | どの店舗から出た案かを記録・絞り込み |
| レシピ | 材料・分量・単価を行で追加、作り方は1行1工程 |
| **原価の自動計算** | 原価合計・1つあたり原価・原価率を入力しながら自動表示 |
| 写真 | 完成イメージ＋工程の2枚。スマホのカメラからそのまま添付可 |
| アレルギー | 特定原材料8品目＋準ずるもの20品目をチェックで選択 |
| 栄養・保存 | エネルギー・たんぱく質・脂質・炭水化物・食塩相当量／保存方法・賞味期限 |

原価率は **30%未満=緑 / 30〜35%=黄 / 35%超=赤** で色分けされます。

## セットアップ

### 前提

`clasp` にログインしている必要があります。認証が切れている場合は先に:

```bash
clasp login
```

ブラウザが開くので、アプリを置きたい Google アカウントでログインしてください。

### 手順

**1. Apps Script プロジェクトとスプレッドシートを作る**

このフォルダで実行します。新しいスプレッドシートと、それに紐づいた Apps Script プロジェクトが同時に作られます。

```bash
clasp create-script --type sheets --title "新商品アイデア共有" --rootDir .
```

**2. スプレッドシートIDを設定する**

作られたスプレッドシートを開き、URL の `/d/` と `/edit` の間のIDをコピーして、`Code.gs` の先頭にある `SPREADSHEET_ID` に貼り付けます。

```js
const SPREADSHEET_ID = 'ここにIDを貼る';
```

**3. コードをアップロードする**

```bash
clasp push
```

**4. 合い言葉を設定する**（これをやらないとアプリは全操作を拒否します）

```bash
clasp open-script
```

ブラウザで Apps Script が開いたら、左の**歯車（プロジェクトの設定）＞ スクリプト プロパティ**で

- プロパティ名: `APP_PASSCODE`
- 値: 社内で共有する任意の合い言葉

を1つ追加して保存します。※合い言葉は clasp からは設定できません。

**5. ウェブアプリとしてデプロイする**

Apps Script の画面右上の「**デプロイ ＞ 新しいデプロイ**」から、種類の歯車で「**ウェブアプリ**」を選び:

- 次のユーザーとして実行: **自分**
- アクセスできるユーザー: **全員**（社内だけなら「Googleアカウントを持つ全員」でも可）

「デプロイ」を押すと `.../exec` で終わるURLが発行されます。**これが社内に配るURLです。**

> URLを知っていても合い言葉を知らない人は中身を見られません。合い言葉は社内だけで共有してください。

**6. 最初に開いたとき**

合い言葉を入れると、スプレッドシートに `アイデア` `材料` `店舗` `イベント` `カテゴリ` の5シートが自動で作られます。手動で作る必要はありません。

そのあと「⚙️ マスタ」タブで**実際の店舗名**を登録してください（初期値として「嬉野本店」「武雄店」が入っています）。

---

## 修正したときの再デプロイ（重要）

コードを直したあと `clasp deploy` を**素で叩くと毎回新しいURLが発行され**、社員がブックマークした古いURLは古いコードのまま動き続けます。

同じURLのまま中身を差し替えるには、既存のデプロイIDを指定して**更新**します:

```bash
clasp push
```

```bash
clasp deployments
```

```bash
clasp redeploy <上で確認したデプロイID> -d "v2 ○○を修正"
```

ブラウザで編集した場合は「デプロイを管理」→ 鉛筆アイコン → バージョンを「**新バージョン**」にして「デプロイ」。これをやらないと反映されません。

## 開発するときの注意

コードを触る前に知っておくと事故を防げる点です。

**1. テンプレートリテラルの中にURLを書かない**

GAS はウェブアプリ配信時にコメントを除去しますが、その処理が引用符の外の `//` をコメント開始と誤認して行末まで削ります。バッククォート文字列の中に `https://…` を直接書くと文字列が閉じられず、**スクリプト全体が構文エラーで停止**します（＝画面は出るがボタンが一切反応しない）。URLは必ず `const X = 'https://…'` のように引用符付きの定数にしてください。

現状 `index.html` はテンプレートリテラルを1つも使っていないので、この問題は起きません。

**2. Tailwind CDN は使えない**

`cdn.tailwindcss.com` のランタイムJITは GAS のサンドボックスiframe内で内部エラーを起こし、JSが全停止します。CSSは `index.html` 内に手書きしてあります。

**3. 原価計算は2箇所にある**

`Code.gs` の `calcCost_()` と `index.html` の `calcCost()` は**完全に同じ式**でなければいけません。GAS にはビルド工程がなく共通モジュールを作れないための二重実装です。片方だけ直すと画面表示とシートの保存値がズレます。

丸めは「**行ごとに丸めてから合計**」に固定しています。合計してから丸めると1円ズレます。

**4. 列を追加するときは `IDEA_COL` を使う**

`Code.gs` の列位置は必ず `IDEA_COL` 経由で参照してください。`getRange(row, 26)` のような数字の直書きをすると、列を1本足しただけで写真や更新日時が静かにズレます。

**5. 書式は `setValues` の前に当てる**

数式インジェクション対策で文字列列を `setNumberFormat('@')` にしていますが、`setValues` の**後**に当てると1回目の書き込みが数式として評価されてしまいます。順序を守ってください。

**6. 採用月は文字列**

採用月は `2026/09` という**文字列**です。テキスト書式にしていないと Sheets が日付型 `2026/09/01` に変換し、読み戻したときに `Date` になって絞り込みが全滅します。
